# Azure Subscription 

## Objetivo Semana #1

Documentar la suscripción utilizada para el proyecto Centinela, sus límites y las decisiones tomadas para evitar costos innecesarios.

---

## Tipo de suscripción

Azure for Students

---

## Crédito disponible

100 USD (Azure for Students)

---

## Región elegida

East US

### Justificación

Se eligió East US porque todos los servicios requeridos por el proyecto están disponibles en esta región y ofrece buena disponibilidad.

---

## Servicios que utilizaremos

- Azure Functions
- Azure App Service
- Azure Service Bus
- Azure Storage Account
- Azure Cosmos DB
- Azure Entra ID

---

## Servicios que NO utilizaremos

- Azure Kubernetes Service (AKS)
- API Management Premium
- Private Endpoints
- Azure OpenAI
- Máquinas Virtuales para producción

---

## Política de costos

- Utilizar siempre los planes gratuitos cuando existan.
- Eliminar recursos que no se estén utilizando.
- Mantener un único Resource Group para facilitar la eliminación completa del proyecto.
- Revisar periódicamente el consumo desde Cost Management.
